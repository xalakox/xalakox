Mockup A — “Quiet Typography”: how it maps to real markdown

Everything is plain GFM: centered hero via <h1 align="center"> / <p align="center">, apps are one-line entries with 22px inline icons, secondary info uses <sub>. The status chips are small shields.io flat badges. No tables, no big badges — the whole README fits in roughly one screen and reads like GitHub’s own UI. Deep detail (feature bullets) is dropped in favor of each app’s website link.
